# 01 需求与验收

本项目对应小影校招 AI Agent 开发岗笔试第 3 题“企业知识问答 Agent”。用户是查询制度或产品问题的员工，目标是取得有原文依据、能说明适用条件和缺口的可靠答案。

## 输入与输出

输入为问题及可选用户/助手对话历史。知识来源为带文档 ID、版本日期的合成制度和 FAQ。所有文档声明为虚构，不代表小影或其他真实企业的制度。

输出必须包含回答、文档 ID 与原文引用、资料缺口、任务状态。需要追问时给出明确问题；执行失败或达到上限时必须明确未完成。

## 功能范围

- 本地 Python CLI，真实模型通过阿里云百炼北京地域 API 调用。
- 提供 `search_documents` 和 `read_document` 两个本地业务工具。
- 模型选择动作，本地执行工具，真实返回进入下一轮模型输入，由模型决定下一步。
- 轻量 RAG：中文 BM25、原 Query 与模型改写 Query、原文读取和引用校验。
- 两种配置：全部 Plus 的 `single`，以及 Flash 预处理＋Plus 主循环的 `split`。
- 合成知识、可执行测试、离线 Mock、真实集成运行入口、实际 Trace 和规定文档。

微调、强化学习、向量服务、图形界面、线上部署和多 Agent 产品架构不在首版范围。开发时使用多个代码辅助 Agent 不代表运行时使用多 Agent。

## 可靠答案的边界

原文中的时间、否定、产品版次和条件必须保留。日期较新、检索分更高或规则更严格都不能单独证明优先级。只检索到 D01 且没有矛盾线索时允许依据 D01 回答，但不能宣称整个公司只有这一份制度。

工具成功返回空结果与工具失败必须区分。前者可补检索后说明资料缺口，后者应说明受故障影响而无法核实。历史助手回答用于理解会话，不能代替当前资料。

程序校验引用的来源、版本和原文存在性；引用是否支持结论还需语义检查。无依据事实、错误引用、未解决冲突却选定唯一答案属于关键缺陷。
