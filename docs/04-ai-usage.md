## AI 的实际范围

- 规划 Agent：技术方案、P1—P6 草案、验收和本人参与安排。原稿由用户提供，原样归档。
- 本次执行 Agent：主循环、模型 HTTP 客户端、配置、边界控制、集成调试及总体整理。
- 检索/工具子 Agent：中文检索、原文读取及对应确定性测试。
- 数据/文档子 Agent：按已有种子整理 JSON、用例、快照、提示词文件，核对原文映射，起草交付文档；对 v3 split 两次真实运行和 v4 single 第一轮做只读 AI 语义审阅并记录残留缺陷。
- 评测子 Agent：离线用例检查、批量运行、对照与评测测试。

P1/P2 的资料和用例由执行 Agent 依据模板约束整理，没有通过百炼调用生成。P3/P4/P5 为运行时提示词，已用于真实首轮，并在实际失败后修订；各轮版本以 Trace 和提示词哈希为准。P6 仅保留可选离线模板，当前未调用。Mock 中的查询改写及策略属于脚本化流程，不能记为千问模型效果。

具体代码辅助模型与工具属于本执行会话环境；业务运行时模型 ID 明确记录为 `qwen-plus-2025-12-01`、`qwen-flash-2025-07-28`。接通检查的响应模型名与指定快照一致，实际参数与用量见运行记录；不推测未公开参数量或未经比较的效果。
